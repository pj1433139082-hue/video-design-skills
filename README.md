# Video Design Skills

一套由需求澄清、视频设计系统、风格样张确认到视频构建与验收的智能体技能工作流。

维护者已使用这套技能产出多条视频。当前发布的是现有工作流基线，后续重点是优化流程、降低重复确认与执行消耗，并整理独立使用时的依赖。这不是从零验证视频能否生成的项目。

## 技能组成

| 目录 | 职责 |
| --- | --- |
| `skills/remotion-consult/` | 澄清需求、提出方向、产出 DESIGN.md 和 Video Design Tokens、确认风格样张 |
| `skills/remotion-build/` | 按设计契约组织字幕、配音、素材、场景、渲染与验收 |
| `skills/remotion-shared/` | 共享规范、类别模板、审美参考与动效组件 |

基本交接：需求 → consult → DESIGN.md / tokens 契约 / 风格样张 → build → 视频与验收证据。

## 当前发布范围

- 收录三个技能目录中的现有说明、参考文件、评估定义和动效源码。
- 保留现有流程；仅将构建指南中个人 Chrome 绝对路径替换为示例占位路径。
- 文档中的工作台、资料库、其他技能、媒体脚本及运行环境属于外部依赖，尚未全部随仓提供。
- 既有视频产出由维护者确认；本次建仓没有重新渲染视频，没有将所有文档断言逐条重新验证。
- `evals/evals.json` 是已有评估定义，其中引用的工作台输入未随仓提供，不能直接当成已通过的自动测试。

因此当前是可审阅、可继续维护的基线，尚不宣称全新环境一键运行。

## 开始使用与维护

1. 阅读对应目录的 SKILL.md 及 [依赖边界](docs/DEPENDENCIES.md)。
2. 在自己的智能体客户端中配置技能目录；本次尚未提供经过验证的安装器。
3. 已有 DESIGN.md 或已确认方向时，优先衔接已有成果，避免重复咨询。
4. 后续流程优化从 [千问办公交接说明](docs/HANDOFF-QWEN.md) 开始。

## 与上游的关系

本仓库是独立维护的视频设计与交付工作流，不是 Remotion 官方项目。Remotion 官方技能见 <https://github.com/remotion-dev/skills>。

外部框架、参考站、字体、音效、模板和镜头卡不因被引用而自动包含在本仓库中。第三方来源与许可清单待后续整理；本次不为来源尚未逐项核对的全部内容统一添加许可证。
