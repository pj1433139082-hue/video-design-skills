# 视频设计系统模板（DESIGN.md 视频版）

> remotion-consult Phase 4 写 DESIGN.md 用。七段结构，每字段具体值不得"待定"，底部附六轴自评分。产出后是 remotion-build 的唯一接口。

## 模板

```markdown
# DESIGN.md — {视频标题}

## 1. 审美方向
- 定位（一段话）
- 关键词：...
- 禁忌：...

## 2. 字幕字体
- caption / title / body 三档字体（避开 AI 字体黑名单，中文配 Noto Serif SC / Noto Sans SC / ZCOOL）
- 画幅基准字号：1080 宽下示例 caption 64px / title 96px（16:9 按比例换算）；示例值须 ≥ `remotion-build/references/video-quality-metrics.md` §字幕硬阈值底线
- **字号字重底线（屏幕文字都是关键字）**：字幕 / 数据 mono / 标题的字号字重底线**此处不复制数字**——唯一事实源 = `remotion-build/references/video-quality-metrics.md` §字幕硬阈值；禁细体小字，改阈值只改该文件一处。
- 字重 / 行高 / 描边+投影可读性
- 高亮模式：word（词级）/ line（整句）/ none

## 3. 配色
- 语义色板（含 captionActive / captionInactive）
- 字幕高亮色在实拍/图上对比度 ≥3:1
- 每场景主色分配

## 4. 时间轴节奏
- fps / 画幅 / 总时长
- 字幕节奏：中文 4-5 字/秒、句间呼吸 200-400ms、句尾 hold ≥800ms
- 场景基准时长 / 转场频次
- **时序假设（重要）**：以上是**起草基准**，不是硬值——**最终时长以配音 TTS ffprobe 实测为准**（build Step 1.5 生成 TTS 后实测每句时长 → 重建 srt → 画面对齐）。consult 定节奏只作起草与审校基准；若文案/句数变动会拉长或压缩，build 阶段以实测覆盖，不回头改设计方向。

## 5. 画面构图
- 安全区（竖屏上下留白 ≥120px）/ 字幕区位置 / 行数 / 最大行内字数 / 标题区分配
- **构图丰富度（硬规则，防"空/简单"，非竖屏思维）**：
  - 每场景 ≥2 个视觉元素（大字 + 素材 + 数据/装饰/背景动效，不许只有居中大字）。
  - **主体在视觉主位、构图有意识（用户实测 2026-08-16）**：主体图（咖啡杯/分子/产品）放**视觉主位**——中央放大、三分线交点、左右平衡均可（**不必全部居中**，但每个位置都要有目的）；**禁"素材窝在左上角/角落当主体"**（那会视觉降级成标注/小标题，正是之前 Entrance 组件把素材推左上角的 bug）。大字标题叠主体下方或旁；角落（左上角）只放 mono 小标注。构图多样通过主体位置变化 + 素材大小/数量/数据动效/背景实现。
  - **动效库充分用**：每场景至少 2 种动效（素材进出场 + 字体动效 + 背景动效 三选二）；背景层带动效（缓慢漂移/粒子/光斑/扫描线），不静止。
  - 分层 z 序：bg（背景动效）→ mid（主体素材）→ fg（前景细节）→ 大字 → 字幕。
  - 素材不足的层用 mmx/Codex 真实生图补充（透明叠加走 `--transparent` 或 `remove_white_bg.py`，不靠 SVG），不空着。

## 6. 转场动效
- 转场选型（cut/fade/slide/punch-in）+ 统一时长
- 入场动效 + 缓动/spring 配置
- 字幕高亮动效

## 7. Video Design Tokens（tokens.ts）
- 见 remotion-shared/video-tokens-spec.md 契约
- 列出本视频覆盖的字段值（继承类别模板，覆盖差异）

## 8. 动效编排大纲（视听设计核心，每句注入动效模板）

> **大纲 = 视听能否表达好的基础，是 DESIGN 最核心的一段，不是后期补**。撰写时每句必须**注入设计好的动效和模板**，不只列"画面内容"：
> - **镜头卡选型**：从 shotcraft demos（video-shotcraft）为每句选 1 张贴合语义的卡，写卡名 + 意图标记 `[copy]`/`[借思路]`。中文片卡多英文占位 → 优先纯光效/内容型可透明化叠加的卡（见 video-shots-spec §一适配性），关键动效句（问句/强调/记忆点/数据）应真 copy。
> - **视觉技巧注入**：从 video-shots-spec §二权威技巧审每句——景别递进/运镜/卡点节奏/动接动/字距扫光，把镜头语言写进大纲（不只列内容）。
> - **素材层级设计**：bg/mid/fg 分层，每句明确素材进出场 + 字体动效 + 与口播的联动（视听结合）；素材不足层预留 mmx 生图（多候选 vision 挑最优）。
> - **关键词设计**：每句 1-2 个大字关键词（与字幕不重复，挑记忆点或补充信息），排版位置/字号/胶囊样式写进大纲。
> - 大纲写得越具体 → 素材生成越贴合 → build 越顺；后期素材若不合大纲，回改大纲或重生成（不是"生成即用"）。

### 8.0 镜头卡借鉴（video-shotcraft = 第二动效库，可选非强制）

> 动效从**两个源**挑：① 总动效库组件（入场/字幕/背景，`_动效库`）；② shotcraft 镜头级动效（运镜/转场/字体动效/节奏/特效，可选）。§8.2 镜头卡列带意图标记 `[copy]`/`[借思路]`，接入步骤唯一事实源 = `remotion-shared/video-shots-spec.md`「镜头卡接入步骤」。中文科普片卡多英文占位 → 借思路；产品/品牌/英文片 → copy。分类速查：

| 想要 | 选镜头卡类 |
|------|-----------|
| 空间运镜感（产品/推近） | `camera`（推拉摇移/3D 俯冲） |
| 音乐卡点/变速强调 | `rhythm`（变速/卡点/冻结） |
| 场景切换 | `transition`（甩镜/隐藏切/擦除） |
| 大字记忆点 | `typography`（字距展开/kinetic/扫光） |
| 氛围增强 | `effects`（光效/粒子/毛刺） |
| UI/产品交互 | `interaction` / `ui-entrance` |
| 首尾 | `opening` / `outro` |
| 数据叙事 | `data` |

**写 §8.2 时镜头卡列可选填**（如 `camera/steep-tilt-glide [copy]`、`typography/gradient-word-sweep [借思路]`），build 照标记执行（`copy`=直 copy demo / `借思路`=借动效思路用总动效库实现）。

**选卡借鉴（不强制；选了就 read 真源码，不凭卡名猜）**：卡名可经 `shotcraft/gallery/api/library.json` 校验存在 → 读该卡全文（frontmatter 语义 + 参数表）→ 按卡内"参考实现"定位准确 demo TSX 路径 copy。中文片卡多英文占位，借思路用总动效库实现（video-shots-spec §一适配性）。自检：若大部分句子镜头卡列为空/相同，说明动效编排不够丰富（对照 §5 画面丰富度硬规则）。

### 8.1 素材清单（mmx 生图，分层次可拼装）
| slot | 素材 | 层次 | 用途 | 生成规格（video-image-spec） |
|------|------|------|------|------|
| bg-1 | 咖啡豆特写 | 背景层 | 场景底色 | broll，底部留字幕负空间 |
| mid-1 | 手冲壶 | 中景层 | 主体 | 主体，构图偏左 |
| fg-1 | 咖啡杯 | 前景层 | 记忆点 | keyvisual 高清 |

> **层次规则**：同场景多素材按 z 序叠加（背景→中景→前景），各自独立进出场动效拼装成动画。素材不足的层用 mmx/Codex 真实生图补充（透明化走视频-image-spec 透明处理链）。

### 8.2 动效编排（每句口播 → 视觉模式 + 镜头卡 + 素材进出场 + 字体动效 + 口播联动 + 证明时刻）
| # | 口播 | 时间 | **视觉模式**（纯场景图+字/纯卡/场景图+透明层） | 镜头卡（shotcraft） | 画面素材（层） | 素材入场 | 素材退场 | 字体动效 | 口播联动 | 证明时刻+动作类型 |

> **视觉模式规则（2026-08-16 实测，防卡动效与场景图重叠/意义不明）**：每句三选一——①`纯场景图+字`（场景图已表达语义，不用卡）②`纯卡`（卡是主画面，自带背景，不用场景图）③`场景图+透明效果层`（仅光效/粒子/扫光层可叠加，不盖场景主体）。卡选型见 `video-shots-spec`「可叠加 vs 主画面卡」。当前版本误区：把粒子柱/扫光/数字滚动等"完整画面卡"叠在场景图上 = 两张皮重叠 + 动效意义不明。
> **动效力度分级（2026-08-17 用户规范：自动定 + 手动覆盖 + 三版本）**：每句标**力度**（强/中/弱）+ **范围**（全屏/局部/仅字）：
> - **自动分级（AI 默认）**：开场/记忆点/强调/收尾=**强**（主画面卡/运镜/大字动效）；数据句=**中**（数据动效）；普通叙事句=**弱**（透明光效层或静态场景图+字）。
> - **手动覆盖**：用户可指定某句力度/范围，覆盖自动值（"这句弱化/这句强"）。
> - **三版本**：每句/全片可出 3 个动效方案（弱/中/强 或 不同卡组合），用户选一个再 build。
> - 规范目标：全片动效**有层次**（不是每句全屏大动效刺眼，也不是全静态单调），力度与句子重要性匹配。
|---|------|------|-------------------|--------------|---------|---------|---------|---------|
| 1 | 从豆子开始 | 0.5-2.8s | camera/steep-tilt-glide（俯冲推进） | bg-1 豆子（背景）+ SHIWEI 大字 | 缩放淡入 | 下句前溶解 | 字距展开 | "豆子"脱口时豆子浮现 |
| 2 | 深烘醇厚 | 3.3-5.6s | typography/gradient-word-sweep（扫光） | mid-1 烘豆（中景）+ mono 数据 | 上滑入 | 溶解出 | mono 数据滚动 | "深烘"处数据闪出 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... |

> **视听结合规则**：素材入场锚定句首关键词、退场锚定句尾；情绪词（"醇厚/回甘"）触发强调动效（扫光/放大）；字体动效与口播同步（词脱口即动）；背景层缓慢漂移制造空间感。
> **证明时刻（借鉴 paper-collage-video proof moments）**：每句填 3 个证明时刻（句首/中段/0.82 终态）+ 动作类型（入场/持续/终态）——build Step 5 按此抽帧 + 连续帧**证明动作真实发生**（平移一帧静态帧 ≠ 动作证明，如粒子堆积/聚光扫过/数字滚动必须连续帧确认）。

### 8.3 验收提示（build 用）
- 每句至少一个素材或字体的动效在场；进出场无跳变；素材层次 z 序正确；抽帧验证素材层 + 字幕层 + 动效。
```

## 9. 参考溯源（写完必填，防"参考了却没继承"）

> Phase 2/3 抓了参考真值后，**明确写出每个设计维度继承自哪个参考**，评审时对照查忠实度（查漏 = 没真继承 = 重做）。无参考（自由设计）标「自由」。

| 维度 | 继承自（URL/库名/品牌 DESIGN.md） | 具体继承点（色值/字体/节奏值） |
|------|----------------------------------|-------------------------------|
| 配色 | 如 `getdesign.md/linear` 或 `设计系统库/linear-DESIGN.md` | `#5E6AD2` 紫 accent、暗底 |
| 字体 | 如 参考站 opencli 抓的 font-family | Noto Serif SC 900 / 字距 |
| 节奏 | 如 参考视频 / 21st.dev 组件 | 字/秒、转场频次、镜头卡名 |
| 构图 | 如 网页参考排版 | 左右分栏 / 字幕负空间位置 |

> 一致性自检：Phase 0 预检有品牌 DNA 时，本表配色/字体/情绪三项必须与品牌基线一致或合理演进（见 consult Phase 3 一致性检查）。
