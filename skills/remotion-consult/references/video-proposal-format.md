# 视频提案格式（Video Proposal Format）

> remotion-consult Phase 3 出提案用。SAFE/RISK 双轨 + memorable-thing。每方向必须覆盖节奏/转场维度。

## 模板

```markdown
## 视频设计提案

### SAFE 方向（品类基线，稳妥）
1. **{方向名}**
   - 审美关键词：...
   - 字幕字体：...
   - 配色：...
   - 时间轴节奏：字/秒、句间停顿、转场频次
   - 构图：安全区/字幕区/主体区
   - 转场风格：cut/fade/slide/punch-in 选型 + 时长
   - 视觉参考描述：（锚定 video-real-library 真实案例）

2. **{方向名}**（同上结构）

### RISK 方向（刻意偏离）
1. **{方向名}**
   - 为什么值得：...
   - 失去什么：...

2. **{方向名}**（同上）

### memorable-thing（想让观众记住的一个视觉/节奏时刻）
一句话锚定，例如："第 3 秒那个推近转场" / "数字像瀑布一样滚落"

### 自检
- 两个方向若只是换色换字体 → 重做
- 两个视频若能互换旁白而不被察觉 → 重做
```

## 方向选择要求
- 每方向必须含节奏/转场维度（视频特有，不能只有颜色/字体）
- 视觉参考用真实案例锚定（"类似 xxx 的字幕风"），不空泛
- memorable-thing 必须有——没有记忆点时刻的视频等于没有设计
