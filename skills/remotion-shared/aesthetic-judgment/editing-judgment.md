# 剪辑审美判别框架（Editing Judgment）

> remotion-consult Phase 4（定节奏/音乐/声画设计）+ remotion-build Step 5（验收成片）共用。把剪辑审美拆成**可判别的六轴**：节奏/音乐/声画配合/转场/叙事/技法，每轴有判断标准和调整动作。原文细节见 `资料库/AI工具/审美参考库/剪辑/`。

## 六轴判别（每轴 1-5 分，任何 <3 触发修订）

| 轴 | 判断标准（怎么判断好坏） | 调整动作（怎么调） |
|----|------------------------|-------------------|
| **节奏** | 剪辑点是否跟内容/情绪走；快慢是否匹配主题；有无机械匀速切 | 调剪辑点；变速（speed ramp）；句子长短调整；切点对齐重点 |
| **音乐** | 什么时候该有音乐/什么时候停；情绪是否匹配；有无卡点/淡入淡出 | 加配乐（BGM）；调进出点；情绪段落配乐；结尾淡出 |
| **声画配合** | 人像与图像怎么配合；字幕/图像是否遮挡主体；声音与画面是否同步 | 分屏布局；字幕放安全区；图像放副区；声画错位调整 |
| **转场** | 转场类型是否匹配场景情绪；时长是否合适；有无滥用/单一 | 换转场类型；调时长；至少两种交替；重点句用强转场 |
| **叙事** | 开头是否抓人；信息密度是否合适；有无记忆点时刻；结尾是否收束 | 重排段落；加钩子开场；压缩拖沓段；加 memorable-thing |
| **技法** | speed ramp/蒙太奇/叠化是否服务于叙事；有无炫技 | 增删技法；技法为叙事服务；不过度堆叠 |

## 与 Remotion 的映射

| 剪辑轴 | Remotion 实现 |
|--------|--------------|
| 节奏 | `interpolate` 变速 / 句间 200-400ms / 场景时长 |
| 音乐 | 阶段 2 配音（当前纯字幕驱动，BGM 走 `@remotion/media`） |
| 声画配合 | 字幕 `CaptionLayer` 位置 / 场景布局 / 安全区 |
| 转场 | motion-library 转场组件选型（95 个里挑） |
| 叙事 | 场景蓝图（第 N 句 → 画面）编排 |
| 技法 | 数据动画/kinetic type/粒子等选择性使用 |

## 使用时机

- **consult Phase 4**：定节奏基准（fast-paced / 克制）+ 转场选型 + 是否需音乐
- **build Step 5**：抽帧验收时六轴打分（节奏看句间、转场看帧、声画看字幕位置）

## 常见判别问题

1. **什么时候要音乐**：情绪要渲染/转场要推动/结尾要收束 → 加；纯信息陈述/快速口播 → 可不加或轻垫底
2. **人像和图像怎么配合**：口播时人像主区+图像副区；演示时图像主区+口播字幕；避免两者抢焦点
3. **字幕遮挡**：字幕永远在安全区，主体构图留负空间给字幕
