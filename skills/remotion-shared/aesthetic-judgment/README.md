# 审美判别框架（Aesthetic Judgment）

> remotion-consult 定方向 + remotion-build 验收共用的**可判别审美流程**。把摄影/剪辑/前端排版拆成六轴，每轴有判断标准和调整动作——让 AI 有依据地判断好坏、知道怎么调，而不是凭感觉。

## 三个判别框架

| 框架 | 六轴 | 何时用 |
|------|------|--------|
| [摄影判别](photography-judgment.md) | 构图/调色/光线/主体/景深/氛围 | 定素材风格 + 验收素材 |
| [剪辑判别](editing-judgment.md) | 节奏/音乐/声画配合/转场/叙事/技法 | 定节奏 + 验收成片 |
| [前端排版判别](layout-judgment.md) | 层级/网格/留白/字体/动效/对比 | 定画面布局 + 验收构图 |

## 核心结构（每轴）

```
判断标准（怎么判断好坏）  →  调整动作（怎么调）
```

任何一轴 < 3 分 → 触发修订（回炉或调整），与 design-build 的 anti-slop 六轴自评同一机制。

## 注入时机

| 阶段 | 用哪个 | 力度 |
|------|--------|------|
| **consult Phase 4** | 摄影（素材风格）+ 剪辑（节奏/音乐）+ 前端（布局） | 定基准 |
| **build Step 5 验收** | 三个都逐轴打分，<3 触发修订 | 验收闸门 |
