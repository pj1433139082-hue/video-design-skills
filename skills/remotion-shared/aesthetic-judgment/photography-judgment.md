# 摄影审美判别框架（Photography Judgment）

> remotion-consult Phase 4（定素材风格）+ remotion-build Step 5（验收素材）共用。把摄影审美拆成**可判别的六轴**，每轴有判断标准和调整动作。参考 design-build 的 anti-slop 六轴自评结构。原文细节见 `资料库/AI工具/审美参考库/摄影/`。

## 六轴判别（每轴 1-5 分，任何 <3 触发修订）

| 轴 | 判断标准（怎么判断好坏） | 调整动作（怎么调） |
|----|------------------------|-------------------|
| **构图** | 主体是否清晰；有无引导线/三分法/对称；负空间是否给足；裁切是否精准 | 重裁（rule of thirds）；加引导线；调机位；留负空间给字幕 |
| **调色** | 色温是否统一；对比度/饱和度是否匹配情绪；肤色是否自然；有无明显色偏 | HSL 校准；调白平衡；青橙/单色调色；降饱和或加对比 |
| **光线** | 主光/补光/轮廓光是否清晰；光比是否合适；有无死黑/过曝 | 调光位；补光；曝光补偿；加轮廓光 |
| **主体** | 主体（人像/静物/风景）是否突出；景深是否虚化到位；主体与背景是否分离 | 对焦主体；调光圈（浅景深）；主体前置；裁掉干扰 |
| **景深** | 层次感是否出来；前后景关系是否清楚；有无杂乱背景 | 调光圈；拉焦；背景虚化；前景遮挡过渡 |
| **氛围** | 情绪是否与主题匹配；颗粒/质感是否统一；有无叙事感 | 加胶片颗粒；调色板统一；加晕影；微动效 |

## 与视频工作流的映射

| 摄影轴 | 视频中对应 |
|--------|-----------|
| 构图 | 视频画面构图（主体位置/负空间给字幕） |
| 调色 | 视频 tokens 配色 + 素材生成 style 词 |
| 光线 | 背景光照层次（AuroraBackground 亮度） |
| 主体 | 场景卡牌/主角元素突出 |
| 景深 | 背景虚化层次（BlurIn/BlurBackground） |
| 氛围 | 整体情绪基调（选预设设计系统） |

## 使用时机

- **consult Phase 4**：定素材风格时，用六轴判断"要什么风格的素材"（如"构图要留负空间给字幕、调色要 teal-orange"）
- **build Step 5**：验收生成/选择的素材时，六轴逐项打分，<3 的项回炉或调整
