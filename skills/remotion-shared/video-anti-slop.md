# 视频反 AI 味黑名单（Video Anti-Slop）

> remotion-consult 与 remotion-build 共用的**判断基线**。网页 AI 味的指纹是"结构同质化"；**视频 AI 味的指纹是"节奏雷同"**——每个模型都吐 `开场 zoom-in → 3 段要点 → fade 收尾 logo` 的同一节拍。核心准则：让不同 brief 产出的视频像不同的片子，而不是同一个模板换皮。

## 一、高频 AI 视频 Slop 模式（命中即降分）

1. **全程同一种字幕节奏** — 每句等长、词级高亮无差别刷屏，没有句间呼吸和重点停顿。
2. **每场居中同构图** — 所有画面都是"主体居中 + 字幕居中"，没有左右权重、景别变化。
3. **全程单一转场** — 全程只有 fade，或全程只有硬切，没有转场语言的变化。
4. **均匀切画面** — 每 N 秒一切（机械节奏），画面切换不与内容/字幕句意对齐。
5. **紫/靛渐变背景默认** — 无理由的紫色渐变开场/转场背景。
6. **统一淡入淡出** — 所有元素入场都淡入，没有 slide/scale/spring 的节奏差异。
7. **emoji 当视觉元素** — 用 emoji 弹出动画充当图标/强调。
8. **空泛旁白字幕** — "欢迎观看""让我们开始""感谢观看"式无信息字幕。
9. **typewriter 滥用** — 全程打字机效果，没有与其他入场方式交替。
10. **"每句都高亮"** — 词级高亮所有词都一样重，没有重点词/非重点词之分。
11. **模板只换字** — 换主题旁白/换数据，画面结构完全不变。

> **自检闸门**："一个人类剪辑师会不好意思为这条片子署名吗？" 如果会，就是 slop。

## 二、六轴自评（视频版 PHE/SRV）

产出任何视频前按六轴自评，每轴 1-5 分；**任何一轴 < 3 必须触发完整修订轮**，不得直接交付。

| 轴 | 检查内容 |
|----|----------|
| **Philosophy** | 节奏是否有多样性（不全程均匀，场景时长/转场频次有变化） |
| **Hierarchy** | 字幕层级是否刻意（重点词/普通词有区分，标题与字幕节奏清晰） |
| **Execution** | 颜色/字体/时长是否引用 tokens.ts（禁止 inline 硬编码） |
| **Specificity** | 文案是否诚实（不编造数据、不写空泛旁白） |
| **Restraint** | 是否拒绝装饰性炫技（无意义粒子/转场、假 UI chrome） |
| **Variety** | 场景/转场是否有至少两种不同处理（不是全部同构） |

> 打分结果可戳进文件顶部注释（如 `/* slop: P4 H5 E5 S5 R4 V3 */`）。

## 三、硬性 Gate（前置规则，与分数无关，直接否决）

1. **Pre-emit self-critique**：交付前先按六轴自评，低于 3 强制重做。
2. **Honest copy**：不编造数据；数据叙事要么用真数字，要么用清晰占位符。
3. **Locked tokens**：颜色/字体/时长必须引用 tokens.ts，禁止 inline 硬编码。
4. **Deterministic motion**：只用 `useCurrentFrame`/`interpolate`/`spring`，**禁 `Math.random` 与浏览器定时器**（每次渲染结果必须一致）。
5. **No uniform pacing**：字幕/场景节奏必须有呼吸（句间停顿、重点句慢放）。
6. **Typography purity**：字幕字体克制，不滥用斜体/描边/全大写装饰。

## 四、反趋同指令

- 跨变体生成时须变换画幅、明暗、字幕风格、转场语言——**"两个视频若能互换旁白而不被察觉，即失败"。**
- 若 brief 带明确创意意图且无类别模板匹配，走 Custom 分支：一次性配色 + 自定义转场组合，同样跑闸门。

> ⚠️ **适用范围（重要）**：节奏多样性/转场变化类规则主要针对**宣传片 / 口播 / 品牌片**（AI 味重灾区）。对**数据可视化视频 / 教程视频 / 学术演示**，**一致性优先**：规整的图表节奏、可预期的转场、字幕全程可读才是对的，"强行加变化"会破坏理解。反 AI 味红线（紫渐变、空泛旁白、typewriter 滥用等）两类都适用。
