> 定位：`remotion-build/SKILL.md` Step 5 的**唯一执行正本**。命令、阈值、台账模板集中于此；改阈值只改本文件一处，SKILL.md 只引用不复制数字。
> 目标（#21）：让"过门禁"真等于不丑——**可运行**（客观命令+阈值）、**可复核**（台账逐行证据）、**降级即非合规**（缺门禁不得冒充通过）。

**台账规则**：
- `PASS` 必须附可复核证据（命令输出的数值、或抽帧文件名+vision 结论）；空口 PASS 无效。
- `SKIPPED` = 本轮主动跳过：须写原因 + 对结论的影响。
- `NOT-RUNNABLE` = 缺工具/技能/环境：须写 blocker（如"taste-skill 本机未装"）。
- **降级红线**：任一 `NOT-RUNNABLE`/`SKIPPED` 落在**审美或动效维度**（5.5/5.6/5.7/5.9/符合性）→ 交付定性**降级为"非合规交付/基线素材"**，并按 §四 话术在交付说明首行标注。**禁把"部分门禁通过"写成"全门禁通过"**。

## 二、动作证明（5.9 客观化，可运行）

**窗口差分命令**（A..B = 某动效/转场窗口的起止帧）：

```bash
ffmpeg -loglevel info -i <成片.mp4> -vf "select='between(n,A,B)',tblend=all_mode=difference,signalstats,metadata=print" -f null - 2>&1 | grep YAVG
```

**判定阈值**：
- 窗口内逐帧 `lavfi.signalstats.YAVG ≥ 0.10` = 该窗口有真实运动（PASS）。
- 窗口内连续多帧 `YAVG ≈ 0` = 静态/冻结 → FAIL（须 vision 复核是"定格设计"还是"漏做动效"）。
- **整片轮播指标**：对全片跑同一命令取 YAVG 均值；**均值 < 0.05 = 疑似图片轮播**（静态切片拼接）→ 触发 §三 全量对账，缺动效实现证据即 FAIL。

**主观层（配合）**：`ffmpeg -vf "fps=4"` 抽连续帧 → vision 判转场平滑 / 无跳变 / 无空帧；平移一帧静态帧 ≠ 动作证明。

## 三、轮播检测判据（防"背景图+字幕+fade"式偷工）

三条**全过**才不算轮播：
1. **客观运动**：整片 YAVG 均值 ≥0.05，且每个 DESIGN 声明的动效窗口 YAVG ≥0.10（§二命令）。
2. **DESIGN→build 动效对账表**：DESIGN §8/§8.2 列的每条动效 → 填实现组件/代码位置/抽帧证据；**§8 写了没做 = 缺实现证据 = FAIL**。
3. **动效多样性**：≥2 种动效类型在场（素材进出场 / 字体 / 背景 / 场景卡 四选二），且转场非全片单一 fade。

## 四、降级定性话术（统一）

交付说明 / PR / 案例文档**首行**必须写：

> 定性：非合规交付/基线素材（原因：门禁 5.7 等 NOT-RUNNABLE——<blocker>；其余门禁见台账）

合规交付则首行写：`定性：合规交付（门禁台账全 PASS，见下表）`。
