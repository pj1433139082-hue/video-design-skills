# 视频素材规格（Video Image Spec）

> remotion-build Step 4 素材生成用。设计-build 的 `image-spec.md` 视频版改造。核心：让生成的图素材看起来就是**这条视频的一部分**，字幕压上去可读。跨 harness 路由沿用 design-build §4。

## 一、规格表字段（对齐 imagegen prompt 结构）

```json
{
  "slot": "scene-1-bg",       // 图位：对应哪个场景
  "scene": "…",                // 场景/背景（prompt 最前）
  "subject": "…",              // 主体
  "style": "…",                // 风格：编码视频设计系统（见二）
  "mood": "…",                 // 情绪
  "color": "…",                // 配色：绑定 DESIGN.md tokens
  "aspect": "9:16",            // 比例：与画幅一致
  "text": "…" 或 null,          // 图内文字（无则 null）
  "composition": "…",          // 构图：给字幕区留负空间
  "constraints": "…",          // 禁止项
  "intent": "broll|keyvisual|slide-bg" // 用途（决定完成度）
}
```

## 二、intent（视频新增维度）

| intent | 用途 | 完成度 | 说明 |
|--------|------|--------|------|
| `broll` | 背景层，字幕压上去 | 中 | 构图必须留负空间（下部/底部给字幕） |
| `keyvisual` | 关键视觉（主体/封面） | 高 | 高清，可作记忆点 |
| `slide-bg` | 图文轮播背景 | 中 | 纯背景，主体弱化 |

## 三、场景大图预留文字区（先排版再构图，实测 2026-08-16）

生成"整屏场景大图"（场景图/背景）时，prompt 必须**为文字/动效预留空间**——否则满幅图叠字必遮挡（大字盖主体/曲线，视觉闭塞）。生图 prompt 统一加：
- **顶部留白安全带**："画面主体在下方三分之二，顶部四分之一纯净背景留白（放标题大字）"——顶部纯色区给大字胶囊。
- **四周留白 10-15%**：主体不顶边，四边留边距。
- **构图疏朗**：场景元素不过密，留呼吸感（满幅=字无处安放）。
- **卡动效叠加句**（表盘/粒子柱等）：prompt 同时预留动效位（如"右侧留白放表盘"）。
- 生成后 vision 验证"顶部留白区纯净可放字、主体不顶边、四周留白"，不符重新生成（配合 build Step 4 素材回校验大纲）。

## 三、分辨率与约束

- **分辨率 ≥ 画幅宽 2x**（竖屏 2160px 宽），防 punch-in 缩放糊。
- 阶段 1 只做**静态图**素材（不引入视频素材）。
- 字幕区负空间：构图主体放画面中上部，底部留纯色/弱化区给字幕。

## 四、路由（跨 harness，沿用 design-build §4）

- **Codex**：内置 `image_gen` 一次一张（免 key），图从 `$CODEX_HOME/generated_images/` **复制到 `工作台/视频/{slug}/assets/`** 再引用。
- **无图工具**（Claude Code 等）→ 规格表转 GPT 提示词，用户生成存 assets/ 后引用。
- **用户给图** → 优先用。

### 透明背景处理链（素材叠加用，不靠 SVG）

主体素材要透明叠加时，按精读从简到繁：

1. **`media_gen.py --transparent`**：PIL 边缘 flood fill 去背景 → `*_transparent.png`。适用纯色底 + 异色主体。
2. **`工作台/图像处理/remove_white_bg.py`**：白底精修（连通性分析只删边缘连通白，保留主体内部浅色/高光，去白边，自动裁剪居中）→ `*_transparent.png`。适用白底高清图，比 flood fill 精细。参数：`-t` 阈值（背景不纯白提高）、`-f` 羽化（白晕减小）、`--output-4k`。
3. **复杂抠图**（毛发/半透明/复杂背景）→ **停下来交用户处理或 Codex**（走 `工作台/图像处理` 流程），不硬抠。

> 素材策略（用户 2026-08-16 反馈）：**素材一律 mmx/Codex 真实生图，不生成 SVG**（SVG 太丑）；透明叠加走上方透明处理链（`--transparent` / `remove_white_bg.py` / 复杂交 Codex）。背景纹理/光效可用 CSS 渐变/Shader（非 SVG）。

## 五、生成 → 校验 → 落位

1. **定规格**：从 DESIGN.md 设计系统 + 场景蓝图出规格表。
2. **生成**：按 intent 路由。
3. **校验（素材验收，不合格重生成，别让坏图混进构图）**：
   - 风格/配色与 DESIGN.md 一致；
   - 构图留字幕负空间；
   - **无 AI 乱码假文字**（AI 生图常出伪文字——放大看图内文字区，乱码 → 重生成或加 `no text` 约束）；
   - **层次符合 §8.1**（bg 底部留白可漂移 / mid 偏左偏右避开字幕 / fg 高清记忆点，z 序正确）；
   - **透明背景可用**（需要叠加时 `--transparent` 生成的 `*_transparent.png` 边缘无杂色）。
4. **落位**：`assets/<slug>-<slot>.webp`，WebP、适度压缩、非首屏不参与（视频逐帧引用）。

## 六、素材层次与拼装动画（动效编排大纲 §8.1 配套）

- **素材分 3 层**：背景层 `bg`（broll，构图底部留字幕负空间，可缓慢漂移）/ 中景层 `mid`（主体，偏左或偏右避开字幕）/ 前景层 `fg`（keyvisual 记忆点，高清）。
- **同场景多素材按 z 序叠加**（bg→mid→fg），每张独立进出场动效拼装成动画（不是单张静态图）。
- 生成时每张素材的**层次 + 构图（偏左/右/居中）**由动效编排大纲 §8.1 决定；素材与字幕区不重叠。
- intent 与层次对应：`broll`→bg 层 / `slide-bg`→bg 弱化 / `keyvisual`→fg 层；mid 层用 broll 或主体。
