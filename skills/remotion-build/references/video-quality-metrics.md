# 视频质量自动化判别指标（Video Quality Metrics）

> remotion-build Step 5 抽帧验收配套：用**客观量化指标**自动判别抽帧/成片质量，替代纯人眼看帧。调研来源：搜索引擎 API + agent-reach（2026-08-16）。分**硬指标**（技术/可读性，自动化门槛，不达标拒收）和**软指标**（审美/构图，参考分，不一票否决）。

## 一、抽帧自动化判别脚本（已落地，纯本地）

`python scripts/media/frame_judge.py preview/*.png` —— 对每张抽帧算：

| 指标 | 算法/权威 | 阈值 |
|------|----------|------|
| 清晰度 | Laplacian 方差 | PASS>40 / WARN>20 / FAIL |
| 空帧/纯色 | 最大色占比（防黑屏/转场透明帧） | FAIL>0.95 |
| 字幕可读性 | 字幕区明暗跨度 WCAG 对比（sRGB 线性化） | PASS≥3 / WARN≥2 |
| 三分法构图 | Sobel 边缘重心距三分线距离 | PASS dx≤0.15 dy≤0.18 |
| 亮度/饱和度 | 防过曝/过暗 | 0.06<L<0.94 |

> **暗色设计亮度说明（实测 sleep-science 2026-08-17）**：近黑基底（Linear 风格 `#010102`）的**刻意暗设计**会让亮度 FAIL（整帧 mean ~8/255）——这是**设计意图，不阻塞**。判据：**看对比度**（白 on 近黑 ≈17:1 PASS 即证明可读），亮度 FAIL 仅作"意外过暗"提示，不是硬门槛。空帧 FAIL（>0.95 纯色占比）同理——数据卡大片留白可能触发，用 `--text-bg-hex` 跳过众数 + vision 确认内容在场。

> 已实测（咖啡因片）：抓到真问题——暖橙字幕 on 奶油底 WCAG 对比仅 ~2.5:1（WARN），DESIGN 写的 3.5:1 算错。这就是自动判别价值。

## 二、硬指标（自动化门槛，不达标拒收）

| 指标 | 官方来源 | 怎么算 | 本地 | 阈值 |
|------|----------|--------|------|------|
| **VMAF** | Netflix/vmaf（GitHub） | 全参考：渲染片 vs 原样片 | ✅ ffmpeg `-lavfi libvmaf` | >80 过 / >90 优 |
| **SSIM** | 全参考结构相似度 | 逐帧 | ✅ ffmpeg 内置（shotcraft 已用） | mean≥0.97 |
| **PSNR** | 像素误差 | 全参考 MSE | ✅ ffmpeg 内置 | >40dB |
| **WCAG 对比度** | W3C WCAG 2.1 | L=0.2126R+0.7152G+0.0722B（sRGB 线性化） | ✅ frame_judge | 正文≥4.5（AA）/ 大字≥3.0 |
| **ASL 平均镜头时长** | Filmmakers Academy | 时长/镜头数 | ✅ `pip install scenedetect` | 宣传片 2-4s / 口播 4-8s |
| **BPM 卡点** | 行业惯例 | librosa 节拍 vs 转场时刻 | ✅ librosa（music-beat-sync 已有） | 偏差 <±1/2 拍 |

> VMAF/SSIM/PSNR 是**全参考**（需原样片/原画帧）；ASL/BPM 需对成片分析。抽帧场景优先用 frame_judge 硬指标。

### 字幕可读性硬阈值（平台调研：B站/知乎/行业 + 广电总局）

| 项 | 阈值 | 来源 |
|----|------|------|
| 字号 | 中文 24-32 号（1080P）；按画面高 1/20~1/10（1080p≈54-108px）；HD 下限 44px | 缔影传媒 / Subanana / BBC 无障碍指南 |
| **视频铁律** | **屏幕上的文字都是关键字**：字幕 caption ≥64px/字重≥800，数据 mono ≥44px/字重≥700，标题 ≥88px/900；禁细体小字注释（用户实测反馈 2026-08-16） | 视频 vs 网页差异：每帧停留短，字小=看不清 |
| 每行字数 | 中文 ≤15 字（建议 13-15）；单屏 15-20 字/3 秒读完；分 2-3 行 | 知瑷迩 / 城大翻译系 |
| 对比度 | 见下方「字幕/文字对比度归类（WCAG 映射）」：字幕/标题按大字 ≥3:1，小字 mono/正文 ≥4.5:1；深底白/浅黄、浅底黑字；禁红绿/蓝黄 | 缔影 / WCAG |
| 位置 | 底部居中、距底 10-15%、不挡脸/LOGO | 缔影 |
| 时间轴 | 每条 ≥1s（≤6s）；尾留 0.5s；中文 ≥1.5s/行；字幕早于语音 0.2-0.3s 出、滞后 0.5s 消 | Subanana / 知瑷迩 / 缔影 |
| 描边 | 2px 描边 / 半透明底 | Subanana |
| **国标** | 广电总局《电影送审字幕技术要求》：2K/HD 片名字幕垂直高度 ≥40px，对白居中不斜体 | 国家广电总局 |

> **字幕/文字对比度归类（WCAG 映射，唯一口径）**：字幕 caption 与标题按 WCAG「大字」规则，对比度 ≥3:1（3.0）；小于 18pt 的数据 mono 与正文 body 按「正文」规则，对比度 ≥4.5:1。实拍/图片背景上用描边 + 背景色保证。改此映射只改本文件，其余文档引用不复制。

> 这些是 **srt/主题级**判别（非抽帧）：build 时逐句核对字号/行数/时长/描边，抽帧时核对对比度/位置。可写进 build Step 1 srt 校验。

### 节奏/转场惯例（平台调研，量化）

| 项 | 惯例 | 来源 |
|----|------|------|
| 卡点/混剪转场 | 0.1-0.3s | 店托易 |
| 慢节奏（风景/情感）转场 | 0.5-1s | 店托易 |
| 前奏/副歌镜头 | 前奏 1.5-2s/切、副歌 0.8-1s/切、结尾 2-3s | 520自媒体 |
| 大脑情绪延迟 | 0.5-1.5s（前 5s 过快完播率反降 37%） | 520自媒体 |
| 字幕动画 | 0.3-0.5s | 知瑷迩 |
| 构图 | 唯一硬量化=黄金分割 1:1.618 与三分交点；视觉均衡属主观 | 知乎《取景构图实施手册》 |

## 三、软指标（审美参考分，不一票否决）

| 指标 | 官方来源 | 怎么算 | 本地 | 阈值 |
|------|----------|--------|------|------|
| **NIMA 美学分** | Google（IEEE TIP 2018） | CNN 0-10 分布取均值 | ✅ `pip install iqa-pytorch`（含 NIMA；需 onnxruntime） | 美学>6.5 / 技术>5.5 |
| **LAION Aesthetic** | LAION-AI/aesthetic-predictor（MIT） | CLIP 特征线性回归 | ✅ transformers/onnx + HF 权重 | >6.5 |
| **CLIP-IQA / LIQE** | AAAI2023 / CVPR2023 | 无参考质量/观感双分 | ✅ iqa-pytorch 或 IQA-ONNX-Models | 与 NIMA 互证 |
| 三分法构图 | 学术+OpenCV | 显著性→主体质心距三分线 | ⚠️ 启发式（frame_judge 已近似） | 质心距<帧宽 5% |
| 动效时长/缓动 | Material Design 3 官方 | durationInFrames/fps 代码内查 | ✅ 代码查（非抽帧） | 出入屏 200-500ms，emphasized 500/decelerate 400/accelerate 200 |

## 四、使用建议（build Step 5）

1. 抽帧 → `python scripts/media/frame_judge.py`（硬指标，必跑，任一 FAIL 触发修订）。
2. **可选**（装 iqa-pytorch 后）：抽帧批跑 NIMA 美学分，>6.5 记一档；美学分横向对比多帧/多版本。
3. 成片 → 需要时 `ffmpeg -i out.mp4 -lavfi libvmaf=ref=原画:log_path=...` 算 VMAF（有原画时）；ASL 用 scenedetect。
4. 动效时长：代码内核对 Material 3 时长区间。
5. 软指标只作参考分，硬指标一票否决；评审面板判据（review-panel）叠加人工审美。
6. **成片运动理解（视频级，补静态抽帧看不到的）**：渲染后 `ffmpeg -y -i out/final.mp4 -vf "fps=4" seq/%03d.png` 抽连续帧序列 → 主模型 vision 一次看 6-10 张，判断：转场是否平滑无跳变、素材进出场是否突兀、动效是否流畅、节奏是否符合 DESIGN §4。只判"运动正确性"（硬：无跳变/无突兀/无静止卡帧），节奏审美不硬卡。可选 `pip install scenedetect` 后 `scenedetect -i out/final.mp4 detect-content` 统计 ASL 对照节奏惯例（口播 4-8s/镜）。
